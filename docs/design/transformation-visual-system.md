# MACS Transformation Visual System — v1

Status: Phase 05 working system for the transformation branch.
Canonical transformation protocol: `executiveusa/maxx-migrations-agentic-systems/icm/site-transformation-protocol/`

## Intent

Make MACS feel like a selective Pacific Northwest father-and-son company before a visitor reads the details.

Keywords:
- human
- editorial
- local
- light
- quiet confidence
- real work
- real people
- Pacific Northwest without cliché

Avoid:
- dark enterprise SaaS
- glowing AI graphics
- card walls
- generic dashboard chrome
- gradient-tech backgrounds
- isometric network illustrations
- decorative motion with no browsing/comprehension job

## Palette

Derived from the current MACS logo plus neutral editorial surfaces.

- Paper / warm white: `#F6F6E9`
- Ink: `#171512`
- MACS blue: `#3A6EA5`
- Signal coral: `#FE6E60`
- Structural gray: `#B4B4B4`
- White: `#FFFFFF`

Color rule: paper + ink dominate. Blue identifies MACS. Coral is a signal, not a background habit.

## Typography

Display: editorial serif system stack (`Iowan Old Style`, `Palatino Linotype`, `Book Antiqua`, `Georgia`, serif).
Body/navigation: clean system sans (`Inter` when available, `ui-sans-serif`, `system-ui`).

Large display type gets tight tracking and restrained leading. Small text gets normal/positive tracking. Avoid condensed SaaS-display typography.

## Layout

- Maximum reading width is intentionally narrower than media width.
- Media may grow large; copy does not.
- Homepage section rule: one thought + one dominant image.
- Use whitespace as pacing, not as leftover space.
- Editorial rows replace repeated card components where possible.

## Media

Priority:
1. Stacy + Stavarai real photography/video.
2. Real client/project artifacts.
3. Real Northwest/business environments.
4. Real product/tool artifacts.

No generated imagery should impersonate client proof.

## Navigation

Minimal persistent header: MACS mark/wordmark + Menu + Fit action. Full navigation opens as a deliberate surface. Primary destinations: Programs, Work, Story, Built Here, Notes, Apply/Fit.

## Motion

Motion exists to reveal more proof, show spatial relationship, or make navigation feel direct. Respect `prefers-reduced-motion`; large moving backgrounds must have a still equivalent. Avoid endless ambient movement.

## Accessibility

- keyboard-operable menu with focus containment and Escape close;
- visible focus;
- semantic headings/landmarks;
- sufficient contrast;
- no essential meaning conveyed only through motion/color;
- real alt text for meaningful media;
- reduced-motion support.

## Quality bar

COLLINS is the Gauntlet bar for restraint, hierarchy, proof density, whitespace, storytelling and mobile quality. MACS must remain recognizably MACS; do not copy their typefaces, copy, imagery, identity, or case-study assets.
